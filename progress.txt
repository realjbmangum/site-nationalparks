7. Deploy: `npx wrangler pages deploy dist`

### Completed

**Printful Sync Worker:**
- Created `workers/printful-sync/` Cloudflare Worker to replace `scripts/printful-sync.ts`
- Worker fetches all Printful sync products, extracts variants, and upserts into D1
- Supports both cron trigger (every 6 hours) and manual HTTP GET
- Extracts `park_slug` from product name ("Yellowstone - Badge Mug" → "yellowstone")
- Detects `product_type` from name keywords (mug/shirt/sticker/poster/tote)
- Full replace strategy: DELETE all rows, INSERT fresh data each sync
- 500ms delay between Printful API calls for rate limiting
- Deployed to: https://printful-sync.bmangum1.workers.dev
- Cron schedule: `0 */6 * * *` (every 6 hours)

**Files Created:**
- `workers/printful-sync/index.ts` - Worker with fetch + scheduled handlers

**Files Deleted:**

### Decisions
- Full table replace (DELETE + INSERT) instead of upsert — simpler, Printful catalog is small
- Used parameterized queries (not string interpolation) for D1 writes
- Worker deployed separately from Pages project, shares same D1 database

### Gotchas
- Free plan limit of 5 cron triggers across all workers — had to free a slot
- `wrangler deploy` overrides secrets set via dashboard — use `wrangler secret put` instead
- Pages env vars and Worker secrets are separate — must set PRINTFUL_API_KEY on the worker, not just Pages

### Blocker
- **PRINTFUL_API_KEY returning 401** — key set via dashboard and wrangler secret but Printful API rejects it. Need to verify/regenerate token in Printful dashboard (Settings → API Access).
