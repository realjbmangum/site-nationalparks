- JSON fields stored as TEXT in SQLite (vs JSONB in Postgres)
- Added helper functions `parseJsonArray` and `parseJsonObject` for D1 JSON handling

### Database Setup Commands
```bash
# Create D1 database (first time only)
npm run db:create

# Initialize schema locally
npm run db:init

# Seed data locally
npm run db:seed

# For production
npm run db:init:prod
npm run db:seed:prod
```

- Boolean fields use 0/1 instead of true/false
- JSON parsing needed for array/object fields from D1
- Must use SSR mode (output: 'server') for D1 access
